## 3. Direct Airline Schedules

### 3.1 Flight Availability API

```json
{
  "origin": "IST",
  "destination": "LHR",
  "date": "2024-10-15",
  "travelers": 2,
  "cabin": "Economy"
}
```

#### Response (excerpt)

| Field | Description |
|-------|-------------|
| `flight_id` | Unique identifier (carrier + flight number + dep time) |
| `carrier` | e.g., `BA`, `TK` |
| `departure` | UTC timestamp |
| `arrival` | UTC timestamp |
| `duration_minutes` | |
| `seat_map_url` | Direct link to carrier seat map |
| `cabin_classes` | Array of available cabin classes with counts |

**Key Points**

- **Direct Carrier Schedules** – data is refreshed every 30 seconds.
- **Multi‑segment itineraries** are handled via chained requests; the engine will auto‑build optimal routing.
- **No hidden fees** – any surcharges (fuel, airport, taxes) are returned explicitly.

### 3.2 Example: Flight Search Flow

1. **User Input** – `origin: IST`, `destination: LHR`, `date: 2024‑10‑15`.
2. **Service Layer** – `FlightSearchService` queries `GDS_Flight_Amadeus` + `GDS_Flight_Sabre`.
3. **Aggregation** – Merge results, de‑duplicate duplicate legs.
4. **UI Rendering** – Feed `[GDS_FLIGHT_SEARCH_WIDGET]` with JSON payload.

## 4. Live Cabin Class Availabilities

### 4.1 Cabin Class Payload

```json
{
  "flight_id": "TK123_20241015",
  "cabin": "Business",
  "available_seats": 12,
  "price_breakdown": {
    "base_fare": 890.00,
    "taxes": 120.50,
    "fees": 15.00,
    "total": 1025.50
  }
}
```

| Cabin | Description | Typical Yield | Availability Update Rate |
|-------|-------------|---------------|--------------------------|
| Economy | Standard seat | 0.5–0.8 | Every 15 s |
| Premium Economy | Extra legroom | 1–1.5 | Every 20 s |
| Business | Lie‑flat seat | 2–4 | Every 30 s |
| First | Suites | 3–6 | Every 30 s |

**Best Practices**

- **Always request the lowest‑cabin first** to avoid unnecessary data transfer.
- Use **webhooks** for critical seat‑change events (e.g., last‑seat availability).

## 5. Official Hotel CRS Rates

### 5.1 Hotel Search API

```json
{
  "location": "IST",
  "check_in": "2024-10-20",
  "check_out": "2024-10-25",
  "room_type": "Standard",
  "adults": 2,
  "children": 0
}
```

#### Response (excerpt)

| Field | Description |
|-------|-------------|
| `hotel_id` | CRS internal reference |
| `name` | Hotel brand or name |
| `rating` | Star rating |
| `room_types` | Array of available room types |
| `rates` | Per‑night cost (currency) |
| `availability_window` | Check‑in dates available |
| `room_inclusion` | Breakfast, Wi‑Fi, etc. |

**Key Points**

- **Real‑time inventory** – data refreshed every minute.
- **Dynamic Pricing** – rates are computed by the CRS using current demand and hotel’s own algorithm.
- **No over‑booking** – CRS enforces booking window limits; attempts to book beyond the window will return `booking_window_exceeded`.

### 5.2 Sample Rate Breakdown

| 2024‑10‑21 | 220.00 | EUR |

## 6. White‑Label Integration – Widgets

> **Widget placeholders** are inserted directly in the front‑end code. Your team will replace them with the actual widget components provided by your SDK.

### 6.1 Flight Widget

```html
<!-- Flight Search & Booking -->
<div id="flight-widget">
  [GDS_FLIGHT_SEARCH_WIDGET]
</div>
```

- **Parameters:** `origin`, `destination`, `date`, `cabin`, `passengers`.
- **Output:** Interactive list of flights with seat maps, fare details, and a “Book Now” button that triggers a GDS seat reservation via a POST to `/flight/booking`.

### 6.2 Hotel Widget

```html
<!-- Hotel Search & Booking -->
<div id="hotel-widget">
  [CRS_HOTEL_INVENTORY_WIDGET]
</div>
```

- **Parameters:** `location`, `check_in`, `check_out`, `room_type`.
- **Output:** Carousel of hotel listings, price calendar, “Reserve” button that posts to `/hotel/booking`.

### 6.3 Styling & Theming

- **CSS Variables** – Override colors, fonts, and spacing.  
- **Accessibility** – Ensure WCAG 2.2 AA compliance; use semantic tags.  
- **Responsive** – Widgets adapt to mobile, tablet, and desktop.

### 6.4 SDK & Documentation

- SDK available for **JavaScript (React/Vue/Angular)** and **Java (Spring Boot)**.  
- Full API reference at: `https://developer.company.com/sdk/docs`.
