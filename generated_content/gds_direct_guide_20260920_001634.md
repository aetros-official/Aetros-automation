## 4. Live Cabin Class Availabilities

### 4.1 Mapping of Cabin Codes

| Code | Cabin Class   |
|------|---------------|
| **E** | Economy       |
| **J** | Premium Economy |
| **C** | Business      |
| **F** | First         |
| **X** | Economy Plus (if supported) |

### 4.2 API Endpoint

| Service | Endpoint | Required Parameters |
|---------|----------|---------------------|
| Amadeus | `/v1/shopping/availability/flight` | `origin`, `destination`, `departureDate`, `adults`, `cabin` |
| Sabre   | `/v1/availability/flight` | `Origin`, `Destination`, `Date`, `ADT`, `CABIN` |

> **Important** – Use the `cabin` filter to restrict results to a particular class; this reduces payload size and improves latency.

### 4.3 Example: Retrieve Business Class Availability for IST–LHR

```http
GET /v1/shopping/availability/flight?origin=IST&destination=LHR&departureDate=2026-10-21&adults=1&cabin=BUSINESS
```

> Response includes:
> - `availability.business`
> - `cabinAvailability.C` (Sabre)  
> - `cabinAvailability.F` (first class)  
> - `cabinAvailability.E` (economy) – for cross‑check
