## 1. Executive Summary  
- **Zero affiliate dependency** – All inventory, pricing, and bookings originate from Amadeus or Sabre Core Engines (airline) and live CRS hotel systems.  
- **Real‑time, up‑to‑second availability** – Eliminates inventory gaps and overbooking.  
- **White‑label, 100 % brand control** – Widgets can be styled to match any corporate look‑and‑feel.  
- **Cost advantage** – No commission, only direct GDS/CRS usage fees.  

**Goal** – Deliver a single‑page, seamless booking experience that pulls live data, shows instant availability, and posts confirmed itineraries directly to airline CRS and hotel CRS systems.

```

|  Frontend UI     | <------> |   Integration Layer  | <------> |  GDS/CRS APIs     |
|  (React/Angular) |          | (Node.js / Spring)   |          | (Amadeus/Sabre)   |
+------------------+          +----------------------+          +------------------+
          ^                            ^                            ^
          |                            |                            |
   [GDS_FLIGHT_SEARCH_WIDGET]   [CRS_HOTEL_INVENTORY_WIDGET]     |
          |                            |                            |
  +-------+--------+           +-------+--------+           +-------+--------+
  |   Flight DB    |           |   Hotel DB     |           |  CRS Auth/Token |
  +----------------+           +----------------+           +----------------+
```

**Key Points**

- **Integration Layer** is the sole mediator between front‑end widgets and GDS/CRS.  
- **Database Caching** (Redis) holds short‑term search results (5‑10 s TTL) to mitigate API latency.  
- **Stateless API Gateway** enforces rate limits and security.

## 4. API Integration Blueprint  

### 4.1 Authentication & Session Management  

| Step | Endpoint | Method | Body | Notes |
|------|----------|--------|------|-------|
| 1 | `/oauth/token` (Amadeus) / `/token` (Sabre) | POST | `grant_type=client_credentials&client_id=...&client_secret=...` | Returns `access_token`, `expires_in` |
| 2 | Store token in memory with TTL. Refresh automatically before expiry. | N/A | N/A | Use JWT or secure vault for secrets. |

**Sample Node.js (axios)**

```js
const axios = require('axios');
const tokenCache = new Map();

async function getAuthToken() {
  const key = 'amadeus';
  if (tokenCache.has(key) && tokenCache.get(key).expires_at > Date.now()) {
    return tokenCache.get(key).access_token;
  }
  const res = await axios.post('https://api.amadeus.com/v1/security/oauth2/token', {
    grant_type: 'client_credentials',
    client_id: process.env.AMADEUS_CLIENT_ID,
    client_secret: process.env.AMADEUS_CLIENT_SECRET,
  });
  const token = res.data.access_token;
  const expiresAt = Date.now() + (res.data.expires_in - 60) * 1000;
  tokenCache.set(key, { access_token: token, expires_at: expiresAt });
  return token;
}
```

### 4.2 Flight Search – Direct Carrier Schedules  

**Endpoint (Amadeus)**  
`GET https://api.amadeus.com/v2/shopping/flight-offers?originLocationCode=NYC&destinationLocationCode=LHR&departureDate=2026-12-15&adults=1`

**Parameters**

| Param | Type | Description | Mandatory |
|-------|------|-------------|-----------|
| originLocationCode | string | IATA 3‑letter code | ✅ |
| destinationLocationCode | string | IATA 3‑letter code | ✅ |
| departureDate | date | YYYY-MM-DD | ✅ |
| returnDate | date (optional) | For round‑trip | ❌ |
| adults | integer | Passenger count | ✅ |
| cabin | string | `ECONOMY`, `BUSINESS`, `FIRST` | ❌ |

**Response Highlights**

- `flightOffers[].itineraries[].segments[]` – direct carrier flights only.  
- `availableSeats` per segment per cabin.  
- `price` (base + taxes) in local currency.  

**Handling Live Cabin Availability**

```js
const token = await getAuthToken();
const res = await axios.get('https://api.amadeus.com/v2/shopping/flight-offers', {
  headers: { Authorization: `Bearer ${token}` },
  params: { originLocationCode: 'IST', destinationLocationCode: 'DXB', departureDate: '2026-12-15', adults: 2, cabin: 'BUSINESS' },
});
const offers = res.data.data;
```
