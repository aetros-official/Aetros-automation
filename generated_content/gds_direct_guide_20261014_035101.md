## 3. GDS Flight Search & Booking

### 3.1 API Endpoints (Amadeus / Sabre)

|---------|---------|-------|
| **Search** | `/v2/shopping/flight-offers` | `/v1/flights/availability` |

```bash
# OAuth2 Client Credentials

grant_type=client_credentials
```

### 3.3 Flight Search Example

```javascript
// GDS_FLIGHT_SEARCH_WIDGET – React Component
import { useState } from 'react';
import axios from 'axios';

export default function GDSFlightSearch() {
  const [query, setQuery] = useState({});
  const [offers, setOffers] = useState([]);

  const search = async () => {
    const res = await axios.post(
      '/api/flight-search',
      query,
      { headers: { Authorization: `Bearer ${token}` } }
    );
    setOffers(res.data.data);
  };

  return (
    <div className="flight-widget">
      <SearchForm onChange={setQuery} onSubmit={search}/>
      <ResultsList offers={offers}/>
    </div>
  );
}
```

#### Backend Endpoint (`/api/flight-search`)

```python
@app.post("/api/flight-search")
async def flight_search(payload: FlightQuery, token: str = Depends(get_token)):
```

| Field | Description | Sample |

| `cabin` | "Economy", "Business", "First" | `"Business"` |
| `availability` | Number of seats | `12` |

> **Real‑time Refresh** – Poll every 30 seconds during active booking session.  

### 3.5 Pricing & Book‑Now Flow

1. **User selects cabin & date** → Widget sends `search` → Flight data returned.  
2. **User picks offer** → Widget posts to `/api/flight-price`.  
3. **Price Validation** – Service calls GDS `/price` to lock the fare.  
4. **Seat Reservation** – GDS booking call (`/book`).  
5. **Payment Integration** – PCI‑DSS compliant gateway receives booking reference.  
6. **Confirmation** – Flight ticket PDF + itinerary emailed to traveler.  

> **Fail‑over Strategy** – If GDS rate changes between price and book, the booking is automatically cancelled and the user is notified to re‑select.
