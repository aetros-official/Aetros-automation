## Executive Overview
This guide provides **authoritative, production‑grade** instructions for integrating **direct GDS (Amadeus / Sabre)** and **CRS hotel** feeds into an enterprise travel portal. All data originates **exclusively** from the carrier‑level core engines—**no third‑party affiliate or OTA layers** are used.  

Key outcomes:

| Goal | Implementation Detail |
|------|------------------------|
| **Zero‑Affiliate Dependency** | All queries route to Amadeus/Sabre Core Engine (flight) and CRS hotel repository (IST). |
| **Live Cabin‑Class & Seat‑Map** | Real‑time cabin inventory, fare‑class codes, and seat‑map geometry retrieved via NDC/OTA XML‑JSON hybrid. |
| **Official Hotel Rates** | CRS‑derived room‑type, rate‑plan, tax, and surcharge data with nightly breakdown. |
| **White‑Label UI** | Plug‑and‑play widgets (`[GDS_FLIGHT_SEARCH_WIDGET]`, `[CRS_HOTEL_INVENTORY_WIDGET]`) for seamless end‑user experience. |
| **Scalable Architecture** | Stateless micro‑services, Kafka‑backed event streaming, and horizontally‑elastic containers. |
| **Compliance** | PCI‑DSS, GDPR, and airline‑specific data‑sharing agreements satisfied. |

## System Architecture & Data Flow
```mermaid
graph TD
    A[Front‑End (React/Angular)] -->|User Search| B[API Gateway (Kong/Envoy)]
    B -->|AuthN/AuthZ| C[Auth Service (OAuth2/OIDC)]
    B -->|Flight Query| D[GDS Adapter Service]
    B -->|Hotel Query| E[CRS Adapter Service]
    D -->|Amadeus/Sabre SOAP/REST| F[Amadeus/Sabre Core Engine]
    E -->|CRS XML/JSON| G[CRS Hotel Engine (IST)]
    F -->|Live Flight & Cabin Data| D
    G -->|Live Hotel Rate Data| E
    D -->|Standardized JSON| H[Cache Layer (Redis Cluster)]
    E -->|Standardized JSON| H
    H -->|Enriched Results| B
    B -->|Response| A
    subgraph "Event Bus"
        I[Kafka Topics: flight.availability, hotel.rates]
    end
    D -->|Publish| I
    E -->|Publish| I
    I -->|Consume| J[Analytics Service]
    J -->|KPIs & Reporting| K[Data Warehouse (Snowflake)]
```

* **Key Characteristics**
  - **Stateless adapters** guarantee hot‑swap of GDS/CRS providers without code changes.  
  - **Event‑driven architecture** captures every availability change for downstream analytics.  
  - **Cache‑first read** (TTL ≤ 30 seconds) reduces latency while preserving real‑time freshness.

## White‑Label Direct‑Booking Integration

### 5.1 `[GDS_FLIGHT_SEARCH_WIDGET]`
```html
<div id="flight-search-widget"></div>
<script type="module">
  import { initFlightWidget } from '/assets/widgets/gds-flight-widget.js';
  initFlightWidget({
    containerId: 'flight-search-widget',
    gdsEndpoint: 'https://api.enterprise.com/v1/gds/flight/search',
    authToken: '<JWT>',
    defaultOrigin: 'IST',
    defaultDestination: '',
    cabinClassOptions: ['Y','W','C','J'],
    onSelect: (flightOffer) => {
      // Pass selected flightOffer to checkout flow
      console.log('Selected flight:', flightOffer);
    }
  });
</script>
```
*The widget calls **only** the internal `/v1/gds/flight/search` endpoint, which proxies to Amadeus/Sabre. No third‑party affiliate URLs are ever referenced.*

### 5.2 `[CRS_HOTEL_INVENTORY_WIDGET]`
```html
<div id="hotel-inventory-widget"></div>
<script type="module">
  import { initHotelWidget } from '/assets/widgets/crs-hotel-widget.js';
  initHotelWidget({
    containerId: 'hotel-inventory-widget',
    crsEndpoint: 'https://api.enterprise.com/v1/crs/hotel/search',
    authToken: '<JWT>',
    market: 'TR',
    checkIn: '2026-11-01',
    checkOut: '2026-11-05',
    onSelect: (roomOffer) => {
      // Forward roomOffer to reservation engine
      console.log('Selected room:', roomOffer);
    }
  });
</script>
```
*All hotel data originates from the **CRS real‑time rate engine**. The widget respects the same security model as the flight widget.*

## API Contracts & Payload Schemas

### Flight Search (POST `/v1/gds/flight/search`)
| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `origin` | string (IATA) | ✅ | Departure airport |
| `destination` | string (IATA) | ✅ | Arrival airport |
| `departureDate` | string (ISO‑8601) | ✅ | Preferred departure |
| `returnDate` | string (ISO‑8601) | ❌ | For round‑trip |
| `cabinClass` | enum(`Y`,`W`,`C`,`J`) | ✅ | Desired cabin |
| `adults` | integer (≥1) | ✅ | Adult pax count |
| `children` | integer (≥0) | ❌ | Child pax count |
| `infants` | integer (≥0) | ❌ | Infant count |
| `maxResults` | integer (≤200) | ❌ | Pagination limit |

**Response (application/json) – `FlightSearchResult`**
```json
{
  "offers": [ <FlightOffer> ],
  "currency": "USD",
  "searchTimestamp": "2026-10-21T12:34:56Z",
  "cacheTTL": 30
