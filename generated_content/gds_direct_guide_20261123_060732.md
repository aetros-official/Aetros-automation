## 1. Executive Summary  
Your portal will be the **single source of truth** for all flight & hotel data in the enterprise environment. Leveraging Amadeus/Sabre GDS for airlines and the CRS for hotels ensures:

- **Real‑time seat & rate availability**  
- **Price accuracy** (no hidden commissions)  
- **Uninterrupted direct booking** – revenue stays with you.  

This guide walks you through the exact technical steps required to surface that data, embed direct booking widgets, and convert traffic into confirmed reservations.

---

## 2. Data Landscape  
| Layer | Source | Key Data Points | Refresh Rate |
|-------|--------|-----------------|--------------|
| **Flight** | Amadeus / Sabre GDS Core Engine | • Direct Carrier Schedules (flight number, departure/arrival times, airports)  <br>• Live Cabin Class Availabilities (economy, business, first)  <br>• Fare Basis, Rule Sets | **Live** (poll 30 s or event‑driven) |
| **Hotel** | CRS Live Rates (IST) | • Room inventory, nightly rates, currency, taxes  <br>• Rate‑Plan hierarchy (refundable, non‑refundable, promotions)  <br>• Availability per night & room type | **Live** (poll 60 s or event‑driven) |
| **Integration** | Your Portal | • White‑label widgets (no 3rd‑party UI)  <br>• API gateway & orchestration | Continuous |

> **Important:** All data is **source‑verified** – no third‑party aggregators.

## 3. GDS Flight Integration  

### 3.1 Direct Schedule Retrieval  
```http
GET https://api.gds.example.com/v1/flights/schedules
```
**Query Params**  
| Name | Type | Description | Example |
|------|------|-------------|---------|
| origin | string | IATA airport code | LHR |
| destination | string | IATA airport code | IST |
| date | string | YYYY‑MM‑DD | 2026‑12‑15 |
| carrier | string | Optional: airline IATA code | BA |

**Response (JSON)**  
```json
{
  "flights": [
    {
      "flightNumber": "BA1234",
      "carrier": "BA",
      "origin": "LHR",
      "destination": "IST",
      "departureTime": "2026-12-15T10:30:00Z",
      "arrivalTime": "2026-12-15T13:45:00Z",
      "duration": 105,
      "equipment": "A380"
    },
    ...
  ]
}
```
> **Tip:** Cache for 5 min for UI latency, but refresh every 30 s for critical seats.

### 3.2 Live Cabin Class Availabilities  
```http
GET https://api.gds.example.com/v1/flights/avail
```
**Body (JSON)**
```json
{
  "flightNumber": "BA1234",
  "carrier": "BA",
  "date": "2026-12-15",
  "cabinClasses": ["Economy", "Business"]
}
```
**Response**
```json
{
  "flightNumber": "BA1234",
  "availability": [
    {
      "class": "Economy",
      "seatsRemaining": 23,
      "fareBasis": "Y",
      "currency": "GBP"
    },
    {
      "class": "Business",
      "seatsRemaining": 4,
      "fareBasis": "J",
      "currency": "GBP"
    }
  ]
}
```

### 3.3 Pricing & Fare Rules  
```http
GET https://api.gds.example.com/v1/flights/fare
```
**Body (JSON)**
```json
{
  "flightNumber": "BA1234",
  "date": "2026-12-15",
  "cabinClass": "Economy"
}
```
**Response**
```json
{
  "baseFare": 245.00,
  "taxes": 35.00,
  "fees": 12.00,
  "total": 292.00,
  "currency": "GBP",
  "fareRules": [
    { "type": "Cancellation", "allow": false },
    { "type": "Refundable", "allow": false },
    { "type": "AdvancePurchase", "days": 7 }
  ]
}
```

> **Note:** All fare rules must be displayed to comply with EU‑261 / U.S. DOT regulations.

## 4. CRS Hotel Integration  

### 4.1 Inventory & Rate Retrieval  
```http
GET https://api.crs.example.com/v1/hotels/rates
```
**Body (JSON)**
```json
{
  "hotelId": "H12345",
  "checkIn": "2026-12-20",
  "checkOut": "2026-12-25",
  "roomType": "Deluxe King",
  "guests": 2
}
```
**Response**
```json
{
  "hotelId": "H12345",
  "name": "Hilton Istanbul Bosphorus",
  "location": "IST",
  "roomType": "Deluxe King",
  "availability": true,
  "nights": [
    { "date": "2026-12-20", "rate": 150.00, "currency": "USD" },
    { "date": "2026-12-21", "rate": 150.00, "currency": "USD" },
    ...
  ],
  "ratePlan": "Non‑Refundable"
}
```

### 4.2 Rate‑Plan & Promotion Rules  
```http
GET https://api.crs.example.com/v1/hotels/rateplans
```
**Body (JSON)**
```json
{
  "hotelId": "H12345",

}
```
**Response**
```json
{
  "hotelId": "H12345",
  "ratePlans": [
    {
      "id": "RP001",
      "name": "Standard",
      "cancellation": "None",
      "promotion": "10% off for 3+ nights"
    },
    {
      "id": "RP002",
      "name": "Flex",
      "cancellation": "Free up to 48h",
      "promotion": null
    }
  ]
}
```
