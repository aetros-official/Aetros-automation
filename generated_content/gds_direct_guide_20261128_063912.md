```
┌───────────────────────┐   REST/GraphQL   ┌───────────────────────┐
│   Client App (Web/APP) │ ──────────────► │   [GDS_FLIGHT_SEARCH_WIDGET] │
└───────────────────────┘                 └───────────────────────┘
            ▲                                      ▲
            │                                      │

            │                                      │
┌───────────────────────┐                 ┌───────────────────────┐
│   [CRS_HOTEL_INVENTORY_WIDGET] │◄─────────────│   CRS Server (Hotel)   │
└───────────────────────┘                 └───────────────────────┘
```

* **[GDS_FLIGHT_SEARCH_WIDGET]** – Front‑end component that queries our GDS connector layer.  
* **[CRS_HOTEL_INVENTORY_WIDGET]** – Front‑end component that queries our CRS connector layer.  
* **Connector Layer** – Handles authentication, rate‑limit management, caching, and data transformation.  
* **Data Lake** – Real‑time sync of schedules, cabin inventory, and hotel rates (CDC).

## 3. Data Sources & Freshness

| Source | Frequency | Key Data Elements |
|--------|-----------|-------------------|
| **Amadeus / Sabre** | 5 min incremental updates | Flight schedules, aircraft types, live seat availability, fare families, pricing rules |
| **CRS (Hotel)** | 1 min real‑time | Property inventory, nightly rates, special offers, room‑type details, cancellation policy |

### 3.1 Data Integrity

- **Transactional Consistency** – Every booking is a single transaction across GDS/CRS.  
- **Audit Trail** – Immutable logs (timestamp, transaction ID, source ID, user agent).  
- **Fallback** – Graceful degradation to last known good data with `cache-expiry: 120s`.

## 4. Flight Search Flow

### 4.1 Endpoint: `/api/flights/search`

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `origin` | `string` | ✅ | IATA code |
| `destination` | `string` | ✅ | IATA code |
| `departureDate` | `YYYY-MM-DD` | ✅ | |
| `returnDate` | `YYYY-MM-DD` | ❌ | Optional |
| `adults` | `int` | ✅ | |
| `children` | `int` | ❌ | |
| `cabinClass` | `enum` (ECONOMY, PREMIUM_ECONOMY, BUSINESS, FIRST) | ❌ | |
| `directOnly` | `boolean` | ❌ | |
| `sort` | `enum` (PRICE, DEPARTURE_TIME, ARRIVAL_TIME) | ❌ | |

**Example Request**

```bash
curl -X POST https://api.yourportal.com/flights/search \
-H 'Content-Type: application/json' \
-d '{
  "origin":"IST",
  "destination":"LHR",
  "departureDate":"2026-12-01",
  "returnDate":"2026-12-07",
  "adults":2,
  "cabinClass":"BUSINESS",
  "directOnly":true,
  "sort":"PRICE"
}'
```
