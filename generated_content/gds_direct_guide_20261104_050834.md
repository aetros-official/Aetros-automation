## Travel & Fare Analysis Guide – Direct GDS/CRS Integration  
*Version 1.0 – Enterprise Travel Portal*  

> **Purpose:** Provide a comprehensive, technical reference for integrating **direct airline schedules, live cabin‑class availability, and official CRS hotel rates** into a white‑label travel booking platform. All data originates **exclusively** from Amadeus / Sabre Core Engines and carrier CRS systems – no third‑party affiliate feeds.

### 2. Direct Airline Schedules – Technical Details  

| Parameter | Description | GDS Field | Example Value |
|-----------|-------------|-----------|---------------|
| **Operating Carrier** | IATA code of the operating airline | `AirlineCode` | `TK` (Turkish Airlines) |
| **Flight Number** | Numeric identifier (incl. suffix) | `FlightNumber` | `TK001` |
| **Departure/Arrival Airports** | ICAO/IATA codes | `DepartureAirport`, `ArrivalAirport` | `IST`, `LHR` |
| **Scheduled Dep/Arr Times** | UTC timestamps (ISO‑8601) | `DepartureDateTime`, `ArrivalDateTime` | `2026-12-15T07:30:00Z` |
| **Effective Dates** | Validity window for the schedule | `EffectiveFrom`, `EffectiveTo` | `2026-01-01` – `2026-12-31` |
| **Day‑of‑Week Pattern** | Binary mask (Mon‑Sun) | `OperatingDays` | `1111100` (Mon‑Fri) |
| **Aircraft Type** | ICAO designator | `AircraftCode` | `A321` |
| **Flight Duration** | Calculated from dep/arr | — | `3h 45m` |

#### 2.1 Live Cabin‑Class Availability  

| Cabin Code | Description | GDS Field | Availability Indicator |
|------------|-------------|-----------|------------------------|
| `Y` | Economy (Basic) | `CabinClassCode` | `SeatsAvailable` (integer) |
| `S` | Economy (Premium) | — | `SeatsAvailable` |
| `C` | Business | — | `SeatsAvailable` |
| `F` | First | — | `SeatsAvailable` |

**API Call Example (REST)**  

```http
POST https://api.amadeus.com/v2/shopping/flight-offers
Content-Type: application/json
Authorization: Bearer {access_token}

{
  "originLocationCode": "IST",
  "destinationLocationCode": "LHR",
  "departureDate": "2026-12-15",
  "adults": 1,
  "travelClass": ["ECONOMY","PREMIUM_ECONOMY","BUSINESS","FIRST"]
}
```

> **Response snippet (live cabin class)**  

```json
{
  "itineraries": [
    {
      "segments": [
        {
          "carrierCode": "TK",
          "flightNumber": "001",
          "departure": { "iataCode": "IST", "at": "2026-12-15T07:30:00" },
          "arrival":   { "iataCode": "LHR", "at": "2026-12-15T11:15:00" },

```

*All seat‑count fields (`seatsRemaining`) are **real‑time** and refreshed on each request – no cached or stale data is presented to the traveler.*

### 3. Official Hotel CRS Rates – Technical Details  

| Parameter | Description | CRS Field | Example |
|-----------|-------------|-----------|---------|
| **Property ID** | Unique hotel identifier within the CRS | `HotelCode` | `IST001` |
| **Room Type** | Standardized room descriptor | `RoomTypeCode` | `DELUXE_KING` |
| **Rate Plan** | Contracted rate name (e.g., BAR, CORP) | `RatePlanCode` | `BAR` |
| **Currency** | ISO‑4217 | `CurrencyCode` | `USD` |
| **Base Rate** | Net nightly price (ex‑tax) | `BaseAmount` | `215.00` |
| **Taxes & Fees** | Aggregated statutory and CRS‑specific fees | `TaxAmount` | `35.00` |
| **Total Price** | Base + taxes (per night) | `TotalAmount` | `250.00` |
| **Availability** | Number of sellable rooms for the night | `RoomsAvailable` | `7` |
| **Check‑in / Check‑out** | Date range | `CheckInDate`, `CheckOutDate` | `2026-12-15` – `2026-12-18` |

#### 3.1 Live Rate Retrieval (SOAP)  

```xml
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/"
                  xmlns:hot="http://crs.example.com/hotel">
   <soapenv:Header/>
   <soapenv:Body>
      <hot:GetHotelAvailabilityRequest>
         <hot:HotelCode>IST001</hot:HotelCode>
         <hot:CheckInDate>2026-12-15</hot:CheckInDate>
         <hot:CheckOutDate>2026-12-18</hot:CheckOutDate>
         <hot:RoomCount>1</hot:RoomCount>
      </hot:GetHotelAvailabilityRequest>
   </soapenv:Body>
</soapenv:Envelope>
```

**Success Response (excerpt)**  

```xml
<hot:GetHotelAvailabilityResponse>
   <hot:Hotel>
      <hot:HotelCode>IST001</hot:HotelCode>
      <hot:RoomType>
         <hot:RoomTypeCode>DELUXE_KING</hot:RoomTypeCode>
         <hot:RatePlanCode>BAR</hot:RatePlanCode>
         <hot:CurrencyCode>USD</hot:CurrencyCode>
         <hot:BaseAmount>215.00</hot:BaseAmount>
         <hot:TaxAmount>35.00</hot:TaxAmount>
         <hot:TotalAmount>250.00</hot:TotalAmount>
         <hot:RoomsAvailable>7</hot:RoomsAvailable>
      </hot:RoomType>
   </hot:Hotel>
</hot:GetHotelAvailabilityResponse>
```

> **Note:** The CRS returns *exact* rates as contracted directly with the property. No markup or affiliate commission is applied.

### 5. Pricing & Fare Construction – Core Algorithm  

```pseudocode
function buildFare(flightOffer):
    baseFare = flightOffer.pricing.base
    taxes    = sum(flightOffer.pricing.taxes)
    surcharges = sum(flightOffer.pricing.surcharges)

    // Airline‑specific fuel surcharge rules
    if flightOffer.carrierCode in ['TK','BA']:
        fuelSurcharge = calculateFuelSurcharge(baseFare, flightOffer.departureDate)
    else:
        fuelSurcharge = 0

    total = baseFare + taxes + surcharges + fuelSurcharge
    return round(total, 2)
```

- **All components** are sourced **directly** from Amadeus/Sabre fare‑rule payloads. No external markup tables are used.

### 8. Sample End‑to‑End Flow  

1. **User selects flight** → `[GDS_FLIGHT_SEARCH_WIDGET]` issues a **real‑time flight‑offers** request.  
2. **Widget returns** schedule + cabin‑class seat counts; user picks a cabin and clicks **“Reserve”**.  
3. **Booking Engine** builds the fare using the algorithm above and calls the **Airline PNR API** → receives a **PNR locator**.  
4. **User proceeds to hotel** → `[CRS_HOTEL_INVENTORY_WIDGET]` queries the hotel CRS for the same travel dates.  
5. **Widget shows** live room inventory + official BAR rate. User confirms → **Hotel reservation API** creates a **Reservation ID**.  
6. **Final Confirmation Page** displays:  

   - Flight PNR, fare breakdown, cabin class, seat number.  
   - Hotel reservation code, room type, total price.  

   All values are **directly sourced**; no third‑party markup is ever introduced.
