## 1. Executive Summary  
This guide equips your development team with a **single‑source, real‑time travel data framework** that eliminates affiliate dependencies, ensuring **maximum margin, brand control, and compliance**.  

Key benefits:  
- **Zero affiliate commission** – 100 % of revenue stays with you.  
- **Real‑time inventory** – seat and hotel availability reflects the actual GDS/CRS state.  
- **White‑label widgets** – integrate seamlessly with your UI without a brand bleed.  
- **Scalable architecture** – built on industry‑standard APIs that support millions of concurrent users.

## 2. Technical Landscape  

| Layer | Technology | Role |
|-------|------------|------|
| **GDS Interface** | Amadeus / Sabre Core Engine | Direct carrier schedules, live cabin classes, fares, seat map, PNR creation |
| **CRS Interface** | Global CRS (e.g., Sabre CRS, Amadeus CRS) | Real‑time hotel rates, inventory, booking |
| **Data Sync** | Streaming Kafka / RESTful Webhooks | Push‑pull of inventory changes in milliseconds |
| **Cache** | Redis / Memcached | Hot‑data caching for high‑velocity reads (flights/hotels) |
| **Analytics** | Snowflake / BigQuery | Historical fare and availability data for dynamic pricing |
| **Front‑End** | React / Vue | Widget rendering, state management |
| **Security** | OAuth 2.0 / JWT | Secure API calls, token rotation |
| **Compliance** | PCI‑DSS, GDPR, IATA Rules | Payment, personal data, and fare data handling |

## 3. Direct Airline Schedules  

### 3.1. Data Acquisition  

| Endpoint | Method | Sample Request | Response |
|----------|--------|----------------|----------|
| `/gds/flights/search` | POST | ```json\n{\n  "origin": "IST",\n  "destination": "NYC",\n  "date": "2026-10-15",\n  "cabin": "Economy",\n  "segments": 1\n}\n``` | XML/JSON with flight numbers, departure/arrival times, duration, aircraft type, seat availability |

### 3.2. Real‑Time Seat Map  
*Use the `seatmap` attribute returned in the search payload to render an interactive seat layout.*  

```json
"seatmap": {
  "rows": 30,
  "columns": 6,
  "layout": [
    {"row": 1, "col": "A", "class": "First", "status": "available"},
    {"row": 1, "col": "B", "class": "First", "status": "booked"},
    ...
  ]
}
```

### 3.3. Handling Exceptions  
- **Flight cancellation** – `status: cancelled` in the response.  
- **No seats** – `cabinAvailability: 0`.

## 4. Live Cabin Class Availabilities  

| Cabin | Code | Availability Field | Notes |
|-------|------|--------------------|-------|
| First | F | `availableSeats.first` | Premium seat map, zero‑commission |
| Business | C | `availableSeats.business` | Often includes lounge access |
| Premium Economy | W | `availableSeats.premiumEconomy` | Mid‑tier, high margin |
| Economy | Y | `availableSeats.economy` | Core revenue engine |

**API Example – Seat Count per Cabin**

```json
{
  "flight": "AF1234",
  "date": "2026-10-15",
  "cabinAvailability": {
    "first": 5,
    "business": 12,
    "premiumEconomy": 28,
    "economy": 150
  }
}
```

## 5. Official Hotel CRS Rates  

| CRS Source | Rate Type | Data Fields | Currency |
|------------|-----------|-------------|----------|
| Sabre CRS | `ratePlan` | `roomType`, `ratePerNight`, `taxes`, `availability` | USD |
| Amadeus CRS | `price` | `price`, `taxes`, `noShowFee` | EUR |

### 5.1. Search Endpoint  

```http
GET /crs/hotels?city=IST&checkIn=2026-10-20&checkOut=2026-10-23&roomCount=1
```

**Response Sample**

```json
{
  "hotels": [
    {
      "hotelId": "HOTEL12345",
      "name": "Grand Istanbul Hotel",
      "address": "123 Sultanahmet, Istanbul",
      "rooms": [
        {
          "roomId": "RM001",
          "roomType": "Deluxe Double",
          "ratePerNight": 120.00,
          "taxes": 12.00,
          "totalPrice": 372.00,
          "availability": true
        }
      ]
    }
  ]
}
```

### 5.2. Rate Rules & Restrictions  

- **Minimum Stay** – `minStay` field.  
- **Advance Purchase** – `advancePurchaseDays`.  
- **Cancellation Policy** – `cancellationPolicy` object with `time` and `penalty`.
