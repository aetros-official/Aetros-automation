> **Audience:** Backend / Frontend Engineers, Product Owners, API Integrators  
> **Scope:** Direct integration with **Amadeus** / **Sabre Core Engines** for flight data and **CRS** for hotel rates – 100 % zero‑party‑affiliate.

> *All data and examples below are **live‑to‑GDS** and **CRS‑direct**. No third‑party links or affiliate code.*

## 1️⃣  Overview

| Category | Source | Key Feature | How It Helps |
|----------|--------|-------------|--------------|
| **Airlines** | Amadeus / Sabre Core Engine (Direct Carrier Schedules) | Real‑time seat inventory, fares, cabin classes | Enables instant booking & seat selection |
| **Hotels** | Central Reservation System (CRS) – Live rates for IST | Rate plans, availability, taxes | Direct booking without intermediaries |
| **Widgets** | `[GDS_FLIGHT_SEARCH_WIDGET]`, `[CRS_HOTEL_INVENTORY_WIDGET]` | White‑label, embeddable UI | Seamless brand‑consistent user flow |

> **Why Direct?**  
> • **Accuracy:** No commission lag.  
> • **Compliance:** PCI‑DSS, GDPR, and airline/hotel contract terms adhered to automatically.  
> • **Control:** Full visibility of seat/tax structure; full control over revenue management.

## 3️⃣  Direct Flight Search – Amadeus / Sabre

### 3.1  Authentication

```http
POST https://api.amadeus.com/v1/security/oauth2/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials
&client_id=YOUR_CLIENT_ID
&client_secret=YOUR_CLIENT_SECRET
```

> Response contains `access_token` (valid 1 h). Store securely, rotate.

### 3.2  Search Endpoint

| Method | URL | Description |
|--------|-----|-------------|
| `GET` | `https://api.amadeus.com/v1/reference-data/airports` | Airport look‑ups |
| `POST` | `https://api.amadeus.com/v1/shopping/flight-offers` | Flight search with cabin, dates, passengers |

#### 3.2.1  Request Body (JSON)

```json
{
  "originLocationCode": "IST",
  "destinationLocationCode": "LHR",
  "departureDate": "2026-10-20",
  "returnDate": "2026-10-27",
  "adults": 2,
  "children": 0,
  "infants": 0,
  "travelClass": "ECONOMY",
  "nonStop": false,
  "maxFlightOffers": 10
}
```

> **Important:**  
> *`travelClass` maps to **Cabin Class** (Economy, Business, First).  
> *`nonStop` = true gives only non‑stop flights.  

### 3.3  Response Highlights

```json
{
  "data": [
    {
      "id": "FL1234",
      "price": {
        "currency": "USD",
        "total": "350.00",
        "base": "300.00",
        "fees": [
          {"type":"tax", "amount":"30.00"},
          {"type":"service", "amount":"20.00"}
        ]
      },
      "itineraries": [
        {
          "segments": [
            {
              "carrierCode": "BA",
              "number": "123",
              "departure": { "iataCode": "IST", "at": "2026-10-20T07:00:00" },
              "arrival":   { "iataCode": "LHR", "at": "2026-10-20T10:00:00" },
              "duration": "PT3H",
              "flightNumbers": ["BA123"],
              "cabin": "ECO",
              "availability": 15
            }
          ]
        }
      ],
      "availability": {
        "seatCount": 15,
        "cabinClass": "ECONOMY",
        "availabilityStatus": "AVAILABLE"
      }
    }
  ]
}
```

> **Key Fields**  
> - `cabin`: maps to **Cabin Class** (ECO, BUS, FRI).  
> - `availability.seatCount`: live seat inventory per cabin.  
> - `fees`: taxes + mandatory surcharges (e.g., airport taxes, fuel surcharges).

## 4️⃣  Direct Hotel Inventory – CRS

### 4.1  Authentication

```http
GET https://crs.example.com/api/oauth/token
Authorization: Basic base64(client_id:client_secret)
```

> Response contains `access_token` (expires 1 h).

### 4.2  Rate Plan & Availability Endpoint

```
GET /api/hotels/search?city=IST&checkIn=2026-10-20&checkOut=2026-10-27&rooms=1
Authorization: Bearer YOUR_TOKEN
```

#### 4.2.1  Sample Response

```json
{
  "properties": [
    {
      "hotelId": "HTL1234",
      "name": "Grand Istanbul Hotel",
      "address": "Sultanahmet, Istanbul",
      "ratePlans": [
        {
          "rateId": "RTP5678",
          "description": "Non‑refundable - 1 Room, 2 Adults",
          "currency": "USD",
          "price": "450.00",
          "breakdown": [
            {"type":"room", "amount":"400.00"},
            {"type":"tax", "amount":"50.00"}
          ],
          "availability": 3
        }
      ]
    }
  ]
}
```

> **Important**  
> *`availability` = rooms left for the entire stay period.*  
> *All taxes are included; no hidden fees.*

```html
<div id="flight-search-container"></div>
<script>
  // Load the core widget library
  const script = document.createElement('script');
  script.src = 'https://widgets.example.com/gds-flight.js';
  script.onload = () => {
    GDS_FLIGHT_SEARCH_WIDGET.init({
      containerId: 'flight-search-container',
      apiKey: 'YOUR_GDS_API_KEY',
      defaultOrigin: 'IST',
      defaultDestination: 'LHR',
      onResults: (data) => {
        // Render results, handle seat selection, etc.
      }
    });
  };
  document.head.appendChild(script);
</script>
```
