## 1️⃣ Overview  

The portal operates **exclusively** on **direct** connections to the **Amadeus** and **Sabre** Core Engines (flight) and the **central reservation systems (CRS)** of partnered hotel chains. No third‑party affiliate feeds are used.  

- **Data ingestion layer**: Persistent TCP/IP sockets (TLS 1.3) → **EDIFACT** (for Amadeus) / **Sabre Open API (SOAP/REST)**.  
- **Normalization**: Unified JSON schema (`TravelDataModel v3.2`).  
- **Cache tier**: Redis‑Cluster (TTL ≤ 30 s for flights, ≤ 300 s for hotels).  
- **Business rules engine**: Drools 7.x – applies fare rules, fare families, and dynamic pricing.  

> **Key Benefit** – Zero latency “look‑aside” to affiliate networks → pure GDS/CRS data, guaranteeing rate parity and inventory freshness.

## 2️⃣ Direct Airline Schedules  

### 2.1 Data Feed Specification  

| Field | Type | Source | Description |
|-------|------|--------|-------------|
| `carrierCode` | String (2) | Amadeus/Sabre | IATA airline designator |
| `flightNumber` | String (4) | Amadeus/Sabre | Numeric flight identifier |
| `departureAirport` | String (3) | Amadeus/Sabre | IATA origin (e.g., **IST**) |
| `arrivalAirport` | String (3) | Amadeus/Sabre | IATA destination |
| `departureTimeUTC` | ISO‑8601 | Amadeus/Sabre | Scheduled departure |
| `arrivalTimeUTC` | ISO‑8601 | Amadeus/Sabre | Scheduled arrival |
| `scheduleStatus` | Enum (OP, CX, LD) | Amadeus/Sabre | Operating, Cancelled, Delayed |
| `effectiveDate` | Date | Amadeus/Sabre | First day of schedule validity |
| `expiryDate` | Date | Amadeus/Sabre | Last day of schedule validity |

> **Implementation tip:** Use the **AmadeSABRE Flight Schedule API** (`/v2/schedules`) with the query parameter `airport=IST&date=YYYY-MM-DD`.  

### 2.2 Sample JSON Payload  

```json
{
  "carrierCode": "TK",
  "flightNumber": "1825",
  "departureAirport": "IST",
  "arrivalAirport": "JFK",
  "departureTimeUTC": "2026-11-10T09:45:00Z",
  "arrivalTimeUTC": "2026-11-10T15:20:00Z",
  "scheduleStatus": "OP",
  "effectiveDate": "2026-01-01",
  "expiryDate": "2026-12-31"
}
```

## 3️⃣ Live Cabin‑Class Availability  

### 3.1 Cabin Matrix  

| Cabin | Code | Typical Seats | Fare Basis Example | Eligibility |
|-------|------|---------------|--------------------|-------------|
| First | `F` | 6‑12 | `TKF12345` | Business/elite members |
| Business | `C` | 28‑40 | `TKC67890` | Premium & corporate |
| Premium Economy | `W` | 45‑70 | `TKW11223` | Flex‑rate customers |
| Economy | `Y` | 180‑250 | `TKY44556` | All passengers |

### 3.2 Real‑Time Availability Call  

**Endpoint**: `GET https://api.amadeus.com/v2/shopping/flight-offers`  

**Required query params**  

| Parameter | Example | Description |
|-----------|---------|-------------|
| `originLocationCode` | `IST` | IATA origin |
| `destinationLocationCode` | `JFK` | IATA destination |
| `departureDate` | `2026-11-10` | Date (UTC) |
| `adults` | `1` | Passenger count |
| `travelClass` | `ECONOMY` | Optional filter (`ECONOMY`, `BUSINESS`, `FIRST`) |
| `max` | `250` | Max results (capped by CRS) |

**Sample response snippet**  

```json
{
  "offers": [
    {
      "id": "1",
      "source": "GDS",
      "itineraries": [...],
      "price": {
        "total": "732.50",
        "currency": "USD"
      },
      "travelerPricings": [
        {
          "travelerId": "1",
          "fareOption": "STANDARD",
          "travelerType": "ADULT",
          "price": {
            "base": "690.00",
            "taxes": "42.50"
          },
          "classOfService": "Y"
        }
      ]
    }
  ]
}
```

### 3.3 Seat‑Class Rules Engine  

| Rule | Logic (Drools DSL) |
|------|-------------------|
| **Rule 1 – Fare Family Eligibility** | `when FlightOffer(classOfService == "C") && Customer.isCorporate() then setFareFamily("BusinessCorporate")` |
| **Rule 2 – Dynamic Upgrade Offer** | `when FlightOffer(classOfService == "Y") && FlightOffer.price.total < 400 && Random() < 0.05 then addUpgradeOption("W", discount=15%)` |
| **Rule 3 – Capacity Guard** | `when FlightOffer.availableSeats(classOfService) < 5 then flagLowInventory()` |

## 4️⃣ Official Hotel CRS Rates  

### 4.1 CRS Data Model  

| Field | Type | Source | Description |
|-------|------|--------|-------------|
| `hotelId` | String (UUID) | Hotel CRS | Unique property identifier |
| `propertyName` | String | Hotel CRS | Brand / name |
| `roomTypeCode` | String (3‑5) | Hotel CRS | Internal room‑type key |
| `ratePlanCode` | String (4) | Hotel CRS | Rate‑plan identifier (e.g., `BAR`, `NONREF`) |
| `baseRate` | Decimal | Hotel CRS | Net rate before taxes |
| `taxes` | Decimal | Hotel CRS | Local taxes & city fees |
| `currency` | String (3) | Hotel CRS | ISO currency |
| `availableRooms` | Integer | Hotel CRS | Real‑time inventory |
| `checkInDate` | Date | Hotel CRS | First night |
| `checkOutDate` | Date | Hotel CRS | Last night |

### 4.2 Live Rate Retrieval  

**Endpoint**: `POST https://api.hotelcrs.com/v1/inventory/search`  

```json
{

  "stayPeriod": {
    "checkIn": "2026-12-01",
    "checkOut": "2026-12-05"
  },
  "roomCount": 1,
  "guestCount": 2

```

**Response (excerpt)**  

```json
{
  "results": [
    {
      "hotelId": "e8f7c9b2-3a1d-4f9b-9c2e-6a5d8c9e0f1a",
      "propertyName": "Istanbul Grand Plaza",
      "roomTypeCode": "DLX",
      "ratePlanCode": "BAR",
      "baseRate": 145.00,
      "taxes": 23.00,
      "currency": "USD",
      "availableRooms": 7,
      "checkInDate": "2026-12-01",
      "checkOutDate": "2026-12-05"
```

> **Note:** All rates are **non‑refundable** unless the `ratePlanCode` explicitly indicates a refundable plan (`REFD`).

## 5️⃣ White‑Label Direct Booking Integration Blueprint  

### 5.1 High‑Level Architecture  

```
+-------------------+      TLS 1.3       +-------------------+
|  Front‑End UI     | <----------------> |  API Gateway      |
| (React/Angular)  |   (OAuth2/JWT)     | (Kong / Apigee)   |
+--------+----------+                    +--------+----------+
         |                                     |
         |   +-------------------------------+ |
         |   |   Service Mesh (Istio)        | |
         |   +-------------------------------+ |
         |               |                     |
   +-----v-----+   +-----v-----+   +-----------v-----------+
   | Flight Svc|   | Hotel Svc |   | Rules & Pricing Svc   |
   | (Go/Java) |   | (Go/Java) |   | (Drools + Node)       |
   +-----------+   +-----------+   +-----------------------+
         |               |                     |
   +-----v-----+   +-----v-----+   +-----------v-----------+
   | GDS/Amadeus|   | CRS/Hotel |   | Redis Cache Layer    |
   +-----------+   +-----------+   +-----------------------+
```

### 5.2 API Contracts (excerpt)

| Method | Path | Auth | Request | Response |
|--------|------|------|---------|----------|
| `GET` | `/api/v1/flights/search` | Bearer JWT | `{origin, destination, departDate, cabin}` | `200 → FlightOffer[]` |
| `POST`| `/api/v1/hotels/search` | Bearer JWT | `{hotelIds, stayPeriod, guests}` | `200 → HotelRate[]` |
| `POST`| `/api/v1/reservations/flight` | Bearer JWT | `{offerId, passengerInfo, paymentToken}` | `201 → Confirmation` |
| `POST`| `/api/v1/reservations/hotel` | Bearer JWT | `{rateId, guestInfo, paymentToken}` | `201 → Confirmation` |

> **All endpoints bypass affiliate redirection** – they talk straight to Amadeus/Sabre (flight) and the hotel’s CRS (hotel).
