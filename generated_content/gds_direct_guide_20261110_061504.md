## 1. Executive Summary  
This guide equips your engineering and product teams with everything needed to embed **direct, live travel inventory** from Amadeus/Sabre into your portal. By bypassing affiliate networks, you:

- **Eliminate markup** – Pass real‑time pricing directly to your customers.  
- **Guarantee seat & room availability** – No “book‑once, sell‑later” surprises.  
- **Accelerate booking flow** – One‑click seat/hotel selection with instant confirmation.  
- **Boost conversion** – Trustworthy, accurate data increases booking confidence.

## 2. Data Source Architecture  

| Layer | Description | Data Flow |
|-------|-------------|-----------|
| **GDS Core Engine** | Amadeus or Sabre API, raw flight schedules & cabin classes. | `Flight Search → GDS → JSON Response` |
| **CRS Engine** | Real‑time hotel rates & availability. | `Hotel Search → CRS → JSON Response` |
| **In‑House Cache** | Edge caching (Redis or Memcached) with TTL set to 30 s for flight data, 60 s for hotel data. | Improves latency while preserving “live” feel. |
| **White‑Label Widget Layer** | Front‑end React/Angular/Vue component that consumes the APIs. | `Widget → API → UI` |
| **Analytics & Logging** | Structured logs (ELK) for audit, SLA, and conversion analysis. | `Logs → Kibana/Prometheus` |

> **Zero‑Affiliate Policy** – All data flows directly from GDS/CRS; no intermediary.

### 5.2. API Flow Diagram  

```
+-----------+        +-------------------+        +------------------------+
|  Frontend |        |  Private API Layer|        | Amadeus/Sabre & CRS    |
|  Widget   +<------>+  (Auth + Throttle) +<------>+  (Live GDS & CRS Data) |
+-----------+        +-------------------+        +------------------------+
      |                         |                         |
      |  Flight Search (POST)   |  Hotel Search (POST)    |
      |  +---------------------+|  +---------------------+
      |  |  Cache Layer (30s/60s)|  |  Cache Layer (30s/60s)|
      |  +---------------------+|  +---------------------+
      |                         |                         |
      |  Response (JSON)        |  Response (JSON)        |
      |<------------------------+<------------------------+
```

- **Authentication** – OAuth 2.0 client credentials grant; token cached for 1 h.  
- **Throttling** – 200 req/min per customer IP; GDS imposes 1 req/5 s per session.

```
POST https://api.yourportal.com/v1/flight/search
```

**Headers**  
```http
Authorization: Bearer {access_token}
Content-Type: application/json
```

