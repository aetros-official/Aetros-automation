### 6️⃣ Booking Links Layout (Affiliate Integration)

1. **Hotel Widget** – Inline “Book Now” button that triggers a lightbox with the affiliate ID embedded.  
   ```html
   <a href="https://www.booking.com/room/12345?aid=YOUR_AFFILIATE_ID" target="_blank">Reserve $120/night</a>
   ```

2. **Flight Comparison** – “Compare & Book” button that opens a pre‑filled Skyscanner search.  
   ```html
   <a href="https://www.skyscanner.com/flight-search?from=NYC&to=HND&days=30&adults=1&partner=YOUR_PARTNER_ID" target="_blank">Get the best fares</a>
   ```

3. **Experience Packages** – “Add to itinerary” links that push to a calendar and record affiliate revenue.  
   ```html
   <a href="https://www.viator.com/experience/12345?partner=YOUR_ID" target="_blank">Book Guided Tour</a>
   ```

4. **Car Rental** – “Rent a Car” button.  
   ```html
   <a href="https://www.rentalcars.com/rent?city=REYKJAVIK&partner=YOUR_ID" target="_blank">Book a vehicle</a>
   ```

5. **Travel Insurance** – “Protect your trip” link.  
   ```html
   <a href="https://www.coverdrive.com/travel-insurance?ref=YOUR_ID" target="_blank">Get insured</a>
   ```

> **Disclosure** – Place a small banner:  
> *“This post contains affiliate links. I’ll earn a commission on purchases made through them at no extra cost to you.”*
