## 2.  Data Foundations

### 2.1  GDS Flight Data

| Field | Description | Example |
|-------|-------------|---------|
| `AIRLINE_CODE` | IATA code | `BA` |
| `FLIGHT_NUMBER` | Carrier flight number | `2834` |
| `DEPARTURE_AIRPORT` | IATA code | `LHR` |
| `ARRIVAL_AIRPORT` | IATA code | `IST` |
| `DEPARTURE_TIME` | UTC timestamp | `2026‑12‑01T12:30:00Z` |
| `ARRIVAL_TIME` | UTC timestamp | `2026‑12‑01T14:45:00Z` |
| `CABIN_CLASSES` | Array of classes | `[{"class":"Y","availability":12,"fare_basis":"Y1234"},{"class":"J","availability":4,"fare_basis":"J5678"}]` |
| `FARE_CLASS` | Booking class | `Y`, `J`, `C` |
| `FARE_CONDITIONS` | Fare rule summary | `Non‑refundable, change fee €70` |
| `PRICE` | Net fare (in local currency) | `€125.00` |

> **Important:** All `availability` counters are live‑time; refresh the widget every 5 seconds for optimal booking success.

### 2.2  CRS Hotel Data

| Field | Description | Example |
|-------|-------------|---------|
| `PROPERTY_CODE` | Hotel identifier | `R3F` |
| `PROPERTY_NAME` | Hotel name | `Renaissance Istanbul` |
| `ROOM_TYPE` | Room category | `Deluxe King` |
| `AVAILABILITY` | Rooms available for date range | `5` |
| `RATE` | Nightly rate (per room) | `€210.00` |
| `CURRENCY` | Currency code | `EUR` |
| `RATE_CONDITIONS` | Conditions | `Free cancellation up to 24 h before arrival` |
| `SPECIAL_OFFERS` | Promotion flags | `{"promo":"EarlyBird","discount":"10%"}` |

> **Note** – CRS rates are updated every 30 seconds; the widget must handle *hot‑refresh* to avoid stale pricing.

### 3.1  Authentication

| Step | Detail | Endpoint |
|------|--------|----------|
| 1. **Client Credentials** | Your portal obtains an access token (OAuth 2.0) | `/oauth/token` |
| 2. **Token Scope** | `flight.read, flight.book, hotel.read, hotel.book` | - |
| 3. **Refresh** | Rotate token every 60 min | `/oauth/refresh` |

> Use *JWT* signed requests to avoid replay attacks. Store the token in memory, not in cookies.

### 3.2  Request Flow

| Layer | Action | Payload |
|-------|--------|---------|
| Widget | User enters search criteria | `{origin, destination, depart_date, return_date, passengers}` |
| API Gateway | Validate & sanitize | |
| GDS/CRS | Search request | `QV/QL/CRS` (XML or REST) |
| GDS/CRS | Response | JSON with schedules or room inventory |
| Widget | Render results | Interactive list + “Book Now” button |

> **Zero‑touch**: The widget communicates directly with the API Gateway; the user never leaves the portal.

### 3.3  Error Handling

| Error Code | Message | Suggested UI Action |
|------------|---------|---------------------|
| `429` | Too many requests | Show “Rate limit exceeded – try again in 30 s” |
| `504` | GDS/CRS timeout | Offer “Retry” and log the incident |
| `400` | Invalid query | Highlight the offending field |
| `401` | Unauthorized | Prompt user to log in again |

> Log every error with a correlation ID for traceability.
