## 1. Executive Summary
The portal delivers real‑time flight and hotel inventory pulled from the Amadeus/Sabre Core Engine (GDS) and the CRS for Istanbul (IST) hotels. By eliminating affiliate networks, we guarantee **zero‑commission** direct bookings, higher margin retention, and end‑to‑end traceability from user search to payment. This guide outlines how to harness the live data, showcase it to users, and embed the booking widgets directly into a white‑label solution.

| Data Layer | Source | Frequency | Format |

## 3. Direct Airline Schedules

### 3.1 Flight Offer Retrieval
```json
GET https://api.gds.example.com/flights?origin=IST&destination=NYC&date=2026-10-20
Accept: application/json
```
**Sample Response (Partial)**
```json
{
  "searchId": "XYZ123456",
  "results": [
    {
      "flightNumber": "TR1234",
      "carrier": "Turkish Airlines",
      "departure": "2026-10-20T06:45:00Z",
      "arrival":   "2026-10-20T18:30:00Z",
      "duration": "12h 45m",
      "segments": [
        {"segmentId":"S1","origin":"IST","destination":"LHR","departure":"2026-10-20T06:45:00Z","arrival":"2026-10-20T09:00:00Z"},
        {"segmentId":"S2","origin":"LHR","destination":"NYC","departure":"2026-10-20T10:00:00Z","arrival":"2026-10-20T18:30:00Z"}
      ]
    }
  ]
}
```

### 3.2 Filtering & Aggregation
Use the `include` & `exclude` parameters to narrow by:

- **Airlines** (`carrier=TR,DL`)
- **Aircraft Type** (`aircraft=737`)
- **Operating Class** (`class=Y,Business,First`)
- **Price Ranges** (`priceMin=200,priceMax=800`)

**Pagination**: 50 results per page.  
**Cache‑Control**: `Cache-Control: no-cache` – to enforce live freshness.


## 6. White‑Label Direct Booking Integration

The portal is designed for seamless white‑label deployment. Insert the following widgets directly into your page to expose live inventory without any affiliate overlays.

### 6.1 Flight Search Widget
```markdown
[GDS_FLIGHT_SEARCH_WIDGET]
```
- **Customization**: `theme`, `layout`, `language` via query params.
- **Output**: Interactive flight list with seat class toggles, instant fare update, and booking button.

### 6.2 Hotel Inventory Widget
```markdown

```
- **Features**: Real‑time price graph, filter by star rating, map view, instant booking button.

> **Integration Tip:** Wrap each widget in a responsive `<div>` with `max-width: 100%;` to maintain mobile usability.

## 7. API & Widget Integration Guidelines

| Step | Action | Endpoint | Auth |
|------|--------|----------|------|
| 1 | Acquire API Key | `/auth/token` | OAuth 2.0 |
| 2 | Fetch flight data | `/flights` | Bearer Token |
| 3 | Pull cabin avail | `/cabinAvailability` | Bearer Token |
| 4 | Query hotel rates | `/hotels` | Bearer Token |
| 5 | Reserve flight | `/reservations/flights` | Bearer Token |
| 6 | Reserve hotel | `/reservations/hotels` | Bearer Token |
| 7 | Confirm booking | `/confirmations` | Bearer Token |

> **SDKs:** Available in **Node.js**, **Python**, **Java**, and **.NET**. All libraries are versioned with Semantic Versioning.

### 7.1 Security
- All calls over `HTTPS`.  
- Mutual TLS optional for high‑volume clients.  
- IP whitelisting and rate limiting (default: 5,000 requests/hr).

### 7.2 Error Handling
- **429** – Rate limit exceeded → back‑off with exponential delay.  
- **503** – Service unavailable → retry after 30 s.  
- **422** – Validation error → return detailed message.

## 8. Conversion‑Optimisation Best Practices

| Element | Recommendation | Rationale |
|---------|----------------|-----------|
| **Clear Call‑to‑Action** | Use `Book Now` buttons styled in brand colors. | Increases click‑through. |
| **Live Availability Badge** | Show `X seats left in Y` in real time. | Creates urgency. |
| **Price Comparison Table** | Show lowest available fare across cabins. | Educates user and reduces abandonment. |
| **Transparent Pricing** | Display breakdown (taxes, fees) before confirmation. | Reduces cancellation rates. |
| **One‑Click Booking** | Pre‑populate PNR data via widget. | Minimises friction. |
| **Cross‑sell** | Recommend nearby hotels when flight is booked. | Upsell revenue. |

> **Analytics**: Track `widget_load_time`, `seats_left_change`, `booking_completion_rate` via embedded event listeners.
