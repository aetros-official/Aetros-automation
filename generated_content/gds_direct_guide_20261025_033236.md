## 1. Overview & Architecture  

| Component | Description | Primary Protocol |
|-----------|-------------|------------------|
| **GDS Connector** | Bi‑directional streaming client to Amadeus & Sabre Core Engines (SOAP/REST over TCP) | HTTPS/WS‑Secure |
| **CRS Connector** | Direct API gateway to carrier‑owned CRS & hotel property CRS (XML‑API, JSON‑REST) | HTTPS/Mutual TLS |
| **Core AI Engine** | Real‑time fare, seat‑class, and hotel‑rate analytics (rule‑based & ML‑enhanced) | Internal gRPC |
| **Data Lake** | Immutable, append‑only storage of raw GDS/CRS messages (Parquet) | S3‑compatible |
| **Canonical Store** | Normalised relational model (PostgreSQL) used by downstream services | SQL |
| **Booking Widgets** | Client‑side UI components that query the **Booking API** directly – no affiliate redirection | JavaScript/HTML5 |
| **Monitoring Stack** | Prometheus + Grafana + ELK for latency, error‑rates, and data integrity | — |

All traffic is **direct** between the portal and the GDS/CRS providers. No 3rd‑party affiliate networks, OTAs, or meta‑search platforms are involved at any point.

## 2. Direct Airline Schedule Ingestion  

### 2.1 Endpoint Specification  

| Provider | Endpoint | Method | Auth | Payload |
|----------|----------|--------|------|---------|
| **Amadeus** | `https://api.amadeus.com/v2/schedule` | POST | OAuth 2.0 Client‑Credentials | `{ "origin": "IST", "destination": "any", "dateFrom": "YYYY-MM-DD", "dateTo": "YYYY-MM-DD" }` |
| **Sabre**   | `https://api.sabre.com/v2/schedule` | POST | OAuth 2.0 Client‑Credentials | Same payload schema |

> **Note:** Both APIs return **incremental schedule updates** (add/delete/modify) using **Event‑Stream (SSE)** when the `X‑Stream‑Mode: incremental` header is set.

### 2.2 Sample Response (Canonical JSON)

```json
{
  "flights": [
    {
      "carrier": "TK",
      "flightNumber": "TK 1921",
      "departure": {
        "airport": "IST",
        "datetime": "2026-11-15T08:30:00+03:00"
      },
      "arrival": {
        "airport": "LHR",
        "datetime": "2026-11-15T10:45:00+00:00"
      },
      "operatingCarrier": "TK",
      "equipment": "A332",
      "scheduleStatus": "ACTIVE"
    }
    // … more rows
  ],
  "meta": {
    "requestId": "c9e1f3a2-...",
    "generatedAt": "2026-10-25T12:03:14Z"
  }
}
```

### 2.3 Normalisation Rules  

| GDS Field | Canonical Column | Transformation |
|-----------|------------------|----------------|
| `carrier` | `airline_iata` | Upper‑case, 2‑char |
| `flightNumber` | `flight_number` | Remove spaces, keep numeric suffix |
| `departure.datetime` | `departure_utc` | Convert to UTC ISO‑8601 |
| `arrival.datetime` | `arrival_utc` | Convert to UTC ISO‑8601 |
| `equipment` | `aircraft_type` | ICAO code → map to A‑320, B‑777, etc. |

All schedule rows are persisted **as‑is** (no enrichment) to guarantee *source fidelity*.

## 3. Live Cabin‑Class Availability & Pricing  

### 3.1 Real‑Time Availability Query  

```http
POST https://api.amadeus.com/v2/shop/flights
Authorization: Bearer <access_token>
Content-Type: application/json
```

**Payload**

```json
{
  "origin": "IST",
  "destination": "LHR",
  "departureDate": "2026-11-15",
  "adults": 1,
  "cabinClass": ["ECONOMY", "PREMIUM_ECONOMY", "BUSINESS", "FIRST"],
  "includeDatedFlights": true
}
```

### 3.2 Response (Key Elements)

| JSON Path | Meaning |
|-----------|---------|
| `offers[].segments[].cabin` | `ECONOMY`, `PREMIUM_ECONOMY`, `BUSINESS`, `FIRST` |
| `offers[].segments[].availability` | Number of seats still bookable (0‑999) |
| `offers[].price.total` | **Live fare** in the currency requested (`EUR`/`USD`/`TRY`) |
| `offers[].price.base` | Base fare before taxes & fees |
| `offers[].price.taxes` | Itemised tax list (airport, fuel, VAT) |
| `offers[].price.fareClass` | Booking class code (e.g., `Y`, `W`, `J`, `F`) |
| `offers[].price.segments` | Per‑segment breakdown – required for multi‑leg itineraries |

> **Important:** The `availability` field is **authoritative** from the carrier’s PNR inventory; no caching beyond a **30‑second TTL** is permitted.

### 3.3 Cabin‑Class Matrix Example  

| Flight | ECONOMY (Y) | PREMIUM_ECONOMY (W) | BUSINESS (J) | FIRST (F) |
|--------|-------------|----------------------|--------------|-----------|
| TK 1921 (IST‑LHR) | 57 seats – €312 | 12 seats – €842 | 4 seats – €2,410 | 0 seats – N/A |
| LH 1234 (IST‑FRA) | 103 seats – €287 | 18 seats – €725 | 6 seats – €2,180 | 2 seats – €4,950 |

## 4. Official Hotel CRS Rate Retrieval  

### 4.1 Hotel CRS Endpoint  

| Provider | Endpoint | Method | Auth |
|----------|----------|--------|------|
| **Marriott CRS** | `https://api.marriott.com/v1/availability` | POST | OAuth 2.0 Client‑Credentials |
| **Hilton CRS**   | `https://api.hilton.com/v2/rooms` | POST | OAuth 2.0 Client‑Credentials |
| **Local Turkish Chains** (e.g., **Divan**, **Rixos**) | `https://crs.<brand>.com/api/v2/rates` | POST | API‑Key (header `X-API-KEY`) |

### 4.2 Unified Request Payload  

```json
{
  "cityCode": "IST",
  "checkIn": "2026-12-01",
  "checkOut": "2026-12-05",
  "rooms": [
    { "adults": 2, "children": 0 }
  ],
  "ratePlanFilters": ["ALL"],   // No affiliate‑only rate plans
  "currency": "EUR"
}
```

```json
    "aircraft_type": { "type": "string" },
    "schedule_status": { "enum": ["ACTIVE","CANCELLED"] }

```

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "HotelRoomRate",
  "type": "object",
  "required": ["hotel_id","room_code","rate_plan_id","total_rate","currency","availability"],
  "properties": {
    "hotel_id": { "type": "string" },
    "room_code": { "type": "string" },

    "cancellation_policy": { "type": "string" }
  }
}
```

All downstream services (search UI, analytics, reporting) consume only these canonical structures.

## 6. White‑Label Direct‑Booking Integration  

> **Zero third‑party affiliate dependency** – the portal calls **only** the internal Booking API that proxies directly to Amadeus/Sabre and the hotel CRS endpoints.

### 6.1 API Surface (REST)  

| Path | Method | Description |
|------|--------|-------------|
| `/api/v1/flights/search` | `POST` | Returns a list of flights with cabin‑class availability & live fare. |
| `/api/v1/flights/book`   | `POST` | PNR creation, seat assignment, payment token capture. |
| `/api/v1/hotels/search`  | `POST` | Returns hotel inventory with CRS rates. |
| `/api/v1/hotels/book`    | `POST` | Room reservation, guarantee (credit‑card token). |
