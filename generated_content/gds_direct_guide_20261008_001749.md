## Travel & Fare Analysis Guide

This guide presents an authoritative analysis of the global aviation sector, focusing on direct airline schedules, live cabin class availabilities, and hotel CRS rates. The information is sourced directly from global distribution systems (GDS) and central reservation systems (CRS).

### Direct Airline Schedules

Our Enterprise Travel Portal provides a direct link to the GDS Core Engine, accessing fresh and accurate information on airline schedules. Users can search and book flights from multiple airlines through the provided GDS_FLIGHT_SEARCH_WIDGET! Here is a sample representation of the widget:

<details><summary> **[GDS_FLIGHT_SEARCH_WIDGET]** </summary>

```html
<script src="path/to/GDS_FLIGHT_SEARCH_WIDGET"></script>
<script>
  App.init({
    apiKey: "YOUR_API_KEY",
    dataSources: [
      {
        source: "Amadeus",
        routes: ["amadeus"]
      }, {
        source: "Sabre",
        routes: ["sabre"]
      }
    ]
  });
</script>
```

Please replace "YOUR_API_KEY" with your personalized API key generated by the travel portal's backend and input the respective GDS providers' routes (amadeus, sabre) to fetch the desired airline schedules.
</details>

This widget enables a seamless traveler experience as GDS providers Amadeus and Sabre are utilized to retrieve real-time flight schedules, benefiting from the latest airline data directly sourced from GDS.

### Live Cabin Class Availabilities

To ensure an optimal experience for your customers, our Enterprise Travel Portal delivers essential information on live cabin class availabilities. By utilizing the GDS Core Engine's routing infrastructure, our end-users can book flights using the specified GDS Pathfinder flights from the widgets:

```html
<script src="path/to/GDS_FLIGHT_QUERY_WIDGET"></script>
<script>
  GDS::Pathfinder.search({
    from: 'LHR', // Set the desired departure airport code
    to: 'SFO', // Set the destination airport code
    travelClass: 'Economy', // Set the desired cabin class (Economy, Premium Economy, Business Class, First Class)
    checkinDate: '2021-09-15', // Set the desired check-in date
    returnDate: '2021-09-22', // Set the desired return date
    numberOfPax: 2 // Set the desired number of passengers
  })
  .then(result => console.log(result.flights))
  .catch(error => console.error(error));
</script>
```

The 'GDS_FLIGHT_QUERY_WIDGET' allows for dynamic search queries to retrieve airfare information, cabin classes, and directives pertinent to your company's white-labeled Enterprise Travel Portal.

### Live Hotel Inventory & Rates

By connecting directly to Amadeus and Sabre GDS, we also provide real-time hotel inventories and rates for direct bookings. You can embed the CRS_HOTEL_SEARCH_WIDGET, offering seamless integration of hotel bookings from both providers:

```html
<script src="path/to/CRS_HOTEL_SEARCH_WIDGET"></script>
<script>
  CRS::HotelSearch.search({ destinationCityCode: 'CAN', travelDuration: 6, checkinDate: '2021-09-15', returnDate: '2021-09-22' })
  .then(result => console.log(result.hotels))
  .catch(error => console.error(error));
</script>
```

This approach ensures that users can reserve hotels directly from their GDS sources, receiving real-time information accessible via the CRS_HOTEL_SEARCH_WIDGET script, enabling an efficient and seamless hotel booking experience.
