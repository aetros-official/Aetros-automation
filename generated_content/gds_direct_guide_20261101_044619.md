## 1. Executive Technical Overview
This module provides a high-fidelity analysis of direct carrier schedules and live Central Reservation System (CRS) inventory for Istanbul (IST). All data is retrieved directly from Global Distribution System (GDS) core engines, bypassing third-party meta-search affiliates. This ensures maximum price transparency, direct seat selection capabilities, and immediate inventory reservation rights.

The architecture below is optimized for **White-Label Direct Booking Integration**, allowing end-users to transact directly with carrier PCCs and hotel chains via embedded widgets.
