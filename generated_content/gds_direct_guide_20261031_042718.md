## 3️⃣ GDS Flight Search & Cabin Availability

### 3.1 API Endpoints

| Service | Endpoint | Method | Auth | Notes |
|---------|----------|--------|------|-------|
| **Amadeus** | `/v2/schedule/airports` | GET | OAuth 2.0 | Returns all scheduled flights from IST. |
| **Sabre** | `/v1/air/schedules` | GET | OAuth 2.0 | Real‑time timetable for all carriers. |
| **Cabin Class Availability** | `/v3/booking/availability` | POST | OAuth 2.0 | Requires `FlightKey`, returns seats per cabin. |

> **Example Payload**  
> ```json
> {
>   "departureAirport": "IST",
>   "arrivalAirport": "NYC",
>   "departureDate": "2026-11-15",
>   "cabin": ["ECONOMY", "BUSINESS"]
> }
> ```

### 3.2 Data Fields

| Field | Description | Sample |
|-------|-------------|--------|
| `FlightKey` | Unique identifier | `AZ123` |
| `DepartureTime` | UTC | `2026-11-15T08:30:00Z` |
| `ArrivalTime` | UTC | `2026-11-15T20:45:00Z` |
| `Airline` | IATA code | `AZ` |
| `Cabin` | `ECONOMY`, `PREMIUM_ECONOMY`, `BUSINESS`, `FIRST` | `BUSINESS` |
| `SeatsAvailable` | Integer | `5` |
| `Price` | `Currency` + `Amount` | `EUR 549.00` |

### 3.3 Widget Integration

```html
<!-- Place this where flight search should appear -->
[GDS_FLIGHT_SEARCH_WIDGET]

<!-- Example configuration (JSON) -->
{
  "source": "Amadeus",
  "endpoint": "/v3/booking/availability",
  "authToken": "YOUR_OAUTH_TOKEN",
  "defaultOrigin": "IST",
  "defaultDestination": "NYC"
}
```

*The widget renders:*

1. **Schedule grid** – departure/arrival times, carrier.  
2. **Cabin selector** – real‑time seats.  
3. **Instant booking button** – tokenized reservation request.

## 4️⃣ CRS Hotel Inventory

### 4.1 API Endpoints

| Service | Endpoint | Method | Auth | Notes |
|---------|----------|--------|------|-------|
| **Central Reservation System (CRS)** | `/v1/hotels/search` | POST | API Key | Filters by location, check‑in/out, star rating. |
| **Rate & Availability** | `/v1/hotels/rates` | POST | API Key | Returns per‑room pricing. |

### 4.2 Data Fields

| Field | Description | Sample |
|-------|-------------|--------|
| `HotelID` | Unique ID | `H12345` |
| `Name` | Hotel name | `Grand Istanbul Plaza` |
| `StarRating` | 1–5 | `4` |
| `RoomType` | `Standard`, `Deluxe`, etc. | `Deluxe` |
| `Availability` | `true/false` | `true` |
| `Rate` | Currency + Amount | `EUR 199.00/night` |
| `CancellationPolicy` | Text | `Free cancellation until 24 hrs` |

### 4.3 Widget Integration

```html
<!-- Place this where hotel inventory should appear -->
[CRS_HOTEL_INVENTORY_WIDGET]

<!-- Example configuration (JSON) -->
{
  "source": "CRS_IST",
  "endpoint": "/v1/hotels/search",
  "apiKey": "YOUR_CRSS_KEY",
  "defaultCheckIn": "2026-11-15",
  "defaultCheckOut": "2026-11-20",
  "rooms": 1
}
```

*The widget renders:*

1. **Hotel list** – name, rating, distance, photos.  
2. **Rate grid** – per‑night price, total stay cost.  
3. **Book now** – reserves instantly via CRS, no third‑party routing.
