# Travel & Fare Analysis Guide  
**Enterprise Travel Portal – Direct GDS/CRS Integration**  
*Source: Amadeus / Sabre Core Engine – Live Carrier Schedules, Cabin‑Class Availability & CRS Hotel Rates for IST (Istanbul Airport)*  

---  

## 📌 Overview  

This document provides a **technical, end‑to‑end blueprint** for building a **white‑label, direct‑booking portal** that consumes **live data** from Global Distribution Systems (GDS) and Central Reservation Systems (CRS) **without any third‑party affiliate overlay**.  

| Component | Primary Data Feed | Key Attributes | Typical Latency |
|-----------|-------------------|----------------|-----------------|
| **Airline Schedules** | Amadeus / Sabre Core Engine | Flight numbers, departure/arrival times, operating carrier, aircraft type, flight legs, connection rules | < 150 ms per request |
| **Cabin‑Class Availability** | Amadeus / Sabre Core Engine | Seats per class (Y/E/B/F...), fare‑basis, booking codes, inventory status (Available / Waitlist / Sold‑Out) | < 200 ms per request |
| **Hotel CRS Rates** | Direct CRS (e.g., Sabre Hospitality Solutions, Amadeus Hotel API) | Property ID, room type, board basis, rate per night, currency, taxes, cancellation policy | < 250 ms per request |

All data is **real‑time, authoritative, and directly sourced** – guaranteeing price parity with the carrier/ hotel’s own booking engine.

## 1️⃣ Direct Airline Schedule & Cabin‑Class Engine  

### 1.1 API Endpoint (REST)  

```http
GET https://api.enterprise-portal.com/v1/gds/flights/search
```

| Query Parameter | Type | Description | Example |
|-----------------|------|-------------|---------|
| `origin` | IATA | Departure airport | `IST` |
| `destination` | IATA | Arrival airport | `LHR` |
| `departure_date` | YYYY‑MM‑DD | Date of travel | `2026-12-15` |
| `return_date` | YYYY‑MM‑DD (optional) | Return leg (round‑trip) | `2026-12-22` |
| `cabin` | Enum (`Y`,`M`,`W`,`C`,`F`) | Preferred cabin (Economy‑Y, Premium‑M, Business‑C, First‑F) | `M` |
| `adults` | int | Number of adult pax | `2` |
| `children` | int | Number of child pax | `1` |
| `currency` | ISO‑4217 | Desired price currency | `EUR` |
| `max_results` | int | Pagination limit (max 200) | `100` |

### 1.2 Embedding the Flight Search Widget  

Place the following **widget placeholder** where the portal UI should render the flight search UI powered directly by the Amadeus/Sabre Core Engine:

```markdown
[GDS_FLIGHT_SEARCH_WIDGET]
```

**Widget contract** (JSON config passed via query string or POST body):

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `target_element_id` | string | ✅ | DOM element where the widget will mount |
| `default_origin` | IATA | ❌ | Pre‑populate origin field |
| `default_destination` | IATA | ❌ | Pre‑populate destination field |
| `default_departure` | YYYY‑MM‑DD | ❌ | Pre‑populate departure date |
| `theme` | enum (`light`,`dark`) | ❌ | UI theme |
| `onSelect` | function | ❌ | Callback receiving the selected `itinerary` object (same shape as API response) |

**Example integration (HTML + inline script):**

```html
<div id="flight-search-root"></div>
<script>
  const config = {
    target_element_id: "flight-search-root",
    default_origin: "IST",
    default_destination: "LHR",
    default_departure: "2026-12-15",
    theme: "dark",
    onSelect: function(itinerary) {
      console.log('User selected', itinerary);
      // Proceed to PNR creation via /v1/gds/reservations/create
    }
  };
  window.loadGDSFlightWidget(config);
</script>
```

## 3️⃣ End‑to‑End Booking Flow (No Affiliate Involvement)  

1. **User searches** flights → `[GDS_FLIGHT_SEARCH_WIDGET]` returns a *live* itinerary.  
2. **User selects** a hotel → `[CRS_HOTEL_INVENTORY_WIDGET]` returns a *live* room rate.  
3. **Portal aggregates** flight + hotel data and presents a *single‑step* PNR / reservation creation request.  

### 3.1 Create PNR (Flight)  

```http
POST https://api.enterprise-portal.com/v1/gds/reservations/create
Content-Type: application/json
Authorization: Bearer <access_token>
```

```json
{
  "itinerary_id": "a1b2c3d4e5",
  "selected_flight": {
    "flight_number": "TK 190",
    "booking_code": "YV9L",
    "cabin": "Y"
  },
  "passenger": [
    {
      "first_name": "Ali",
      "last_name": "Kara",
      "type": "ADT",
      "document_type": "P",
      "document_number": "X1234567",
      "date_of_birth": "1990-04-12"
    }
  ],
  "contact": {
    "email": "ali.kara@example.com",
    "phone": "+90 555 123 4567"

    "method": "card",
```

> **Response:** `PNR` with GDS‑assigned record locator (e.g., `ABCDEF`).
